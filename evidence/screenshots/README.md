# Evidence index

All screenshots are from the HTB Academy module **Attacking Web Applications with Ffuf** (two lab sessions, 26–27 October). The lab target was reset several times, so target IPs and ports differ between captures.

**Redaction policy:** flags, the HTB VPN address, the HTB account ID / Pwnbox hostname in shell prompts, and the browser URL bar (Pwnbox VNC URL) are covered with labelled black boxes. Nothing else was altered. Lab target IPs/ports are left visible as historical session values.
